# XYRON WEBTECH - Interactive Vinayagar Chathurthi

## Run
npm install
npm run dev

### Experience
- Page 1 has many floating 3D-style CSS kolukkattai.
- One click sends a group of six animated SVG rats from the bottom toward the selected kolukkattai.
- The rats jump around the scene and converge on the sweet before the wishes page opens.
- Page 2 continuously floats 3D-style balloons upward and drops flower petals.
- A looping festive melody is generated with the browser Web Audio API after the page transition.
- The wishes page has a custom CSS/SVG 3D-style Vinayagar illustration and XYRON WEBTECH branding.
- No emoji is used as the main visual artwork.
